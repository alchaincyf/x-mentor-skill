# Tibo核心准则：用自己的数据修正内容直觉

验证状态：原帖已用登录态Chrome全文读取；以下为作者自述的概括，未取得其原始数据。原文以链接为准，本仓库不包含账号后台数据或本机采集快照。

## 8条经验与1条底线

Tibo自述自2020年以来发过6000多条帖，出售过X增长工具，并回查了自己的表现。他的观察是：小号回复可能比自发帖更容易被发现；超过600字符的帖子胜过一句话；真实金额增强具体性；一句话偶有爆款但不稳定；陈述式开头优于提问；某次修改开头重发有效；可反复使用的指南更易被收藏；生活故事的点赞中位数超过点名产品的帖子。他另强调长期、持续发布。

这组经验最有用的是用自己的历史修正经验法则。它没有提供随机实验、帖子年龄控制、样本分类细节或中文受众数据，不能解释成平台算法定律。

## 花叔的迁移方式

- 日常记录真实项目的动机、试错、钱或额度、结果；选有读者用途的部分发。为花叔写作时保留「从来不会写代码、用AI做产品」的本人视角；其它用户以其真实经历为准。
- 让新读者既能看到作品，也能理解自己拿去做什么。免费开源/教程是交付，具体成果是证据，作者的选择与经历提供记忆点。
- 长短服从信息完整性。英文600字符不是中文600字；Article、视频附文、Thread分别评估。不能因这条帖就强迫每条写长。
- 金额只有来源真实且有关时才用；没有金额，用真实用时、尝试次数、订阅额度或前后差异。不给产品效果编增长百分比。
- 「生活比产品强」在本账号尚未得到支持：应先用本账号数据检查；生活内容保留人味，不必转成生活方式博主。
- 「小号多回复」不能照搬给6万多粉的账号。回复已有问题、展示用户成果、参与相关同行讨论；不群发、不互赞、不机械抢热帖。
- 短句与提问都可保留；需要有独立意思或真实交流目的，不用句式筛掉本人表达。
- 30分钟重发只作为Tibo的个案。花叔默认观察24小时、72小时，错字事实可及时纠正；再包装要有新增价值，不自动删除、刷屏或重复发布。
- 持续以周为运营单位，选择能长期承受的节奏；不为了连续天数挤占创作或杜撰经历。

## 发布前四问

1. 这条讲的是我亲自经历的什么，还是有来源的他人信息？
2. 陌生读者先看到的结果/判断是什么，有没有证据？
3. 他为什么要收藏、回复、关注或点开链接？本条只需明确一个主要目标。
4. 下次用什么指标、什么时间窗判断它值不值得继续？

## 纠错与升级

2026-10-11停用：120—130字符硬限制、外链必腰斩、回复等于150赞、默认60%英文、换到10点就增数倍。原因分别为内容与账号差异、缺乏可迁移因果证据、误读概率权重、没有受众证据、历史相关性混淆。

每次回流要写来源、日期、样本与适用范围。单帖经验是候选；两个观察窗口的可比成熟样本仍支持，再改默认流程。保留反例，优先更新错误结论。
